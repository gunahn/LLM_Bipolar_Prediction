# Supplementary analyses

Scripts reproducing the supplementary results and the two model-agnostic main
figures. Each writes tables/figures into `results/` and `results/figures/`.

| Script | Manuscript item | Output |
|---|---|---|
| `S_demographics.py` | Table 1 | `cohort_demographics.csv` |
| `S_feature_importance.py` | Figure 2 | `feature_importance.csv`, `Figure2_baseline_feature_importance.png` (2,000× family-clustered bootstrap) |
| `S_prompt_comparison.py` | Figure 3, Suppl. S9 | `prompt_ab_*`, `Figure3_prompt_comparison.png` (5-seed paired t-test) |
| `S_supervised_imbalance_grid.py` | Suppl. S11 / Table S4 | `supervised_imbalance_grid.csv` (4 classifiers × 3 resamplers) |
| `S_llm_vs_ml_significance.py` | Suppl. S8 | `llm_vs_ml_significance.json` (family-clustered paired bootstrap + notes) |
| `S_clinician_benchmark.py` | Suppl. S10, Figure S2 | `clinician_baseline_metrics.csv`, `FigureS2_clinician_baseline.png` |

## Expected inputs (generated by the main pipeline)
- `results/ml_matrix_n141.npz` — keys `X, ybin, y3, feat_names, famid, fold_train, fold_test`
  (write this from `02_supervised_baseline.py`).
- `results/promptAB_percase.csv` — per-seed minimal/clinician predictions from
  `03_fewshot_llm.py` at K=0 (`--prompt minimal` and default clinician).
- `results/best_llm_percase.csv`, `results/best_supervised_oof.csv` — for the significance test.
- `data/clinician_baseline_predictions.csv` — clinician-panel predictions (not committed).
- `data/Bipolar_Data.xlsx` — raw workbook (not committed).

Bootstrap replicate count is unified at **2,000** across all analyses, matching the manuscript.
