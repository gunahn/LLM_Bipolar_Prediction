# Manuscript figures

Figures for "Clinician-Informed Zero-Shot Large Language Models ... Predicting Bipolar Disorder Onset in Depressed Adolescents" (n = 141; 27 converters, 19%).

## Main figures
- **Figure1_learning_curve_roc_operating_point.png** — (a) AUROC vs number of labeled examples k for few-shot LLMs vs a supervised learning curve and full-data reference lines; (b) ROC of the best LLM configurations vs supervised ML; (c) sensitivity/specificity at the Youden-optimal threshold.
- **Figure2_baseline_feature_importance.png** — standardized logistic-regression coefficients with 2,000× family-clustered bootstrap 95% CIs (* p < 0.05).
- **Figure3_prompt_comparison.png** — minimal vs clinician-informed zero-shot prompt on the same model (5 seeds): (a) ROC; (b) sensitivity–specificity trade-off vs threshold; (c) 5-seed paired reproducibility (paired t-test p = 0.006).

## Supplementary figures
- **FigureS1_prevalence_ablation.png** — prompt ablation: prevalence stated (V1) vs removed (V2), AUROC by k for Sonnet and Haiku.
- **FigureS2_clinician_baseline.png** — human expert benchmark: pooled confusion matrix (n = 24, 6 converters) and the clinician's pooled operating point against the clinician-informed LLM ROC.
